# Aveno Academy

Адаптивный лендинг практического курса AI. Исходники сайта находятся в `dist/`: HTML, CSS и JavaScript без сборки и сторонних клиентских зависимостей.

## Локальный запуск

```sh
python3 -m http.server 4173 --directory dist
```

Откройте http://localhost:4173.

## Контакты и заявки

- WhatsApp: `+7 700 360 53 00` — ссылки формируются в `dist/app.js`.
- Instagram: `aveno_academy`.
- Все CTA открывают WhatsApp с подготовленным сообщением.
- Форма проверяет имя и телефон, затем открывает WhatsApp с заполненной заявкой. Посетитель должен самостоятельно отправить сообщение. Сайт сообщает об этом до отправки и после неё; не заявляет, что контакт уже получен.
- Сайт не хранит контакты, не отправляет их автоматически и не подключён к CRM. Если нужен независимый сбор заявок, необходимо согласовать место хранения и подключить серверный обработчик.

## Контент

Эмблема — оригинальный предоставленный файл `2.png`. В оформлении используется CSS-кадрирование оригинала. Шрифт Manrope размещён локально, лицензия — `dist/assets/OFL.txt`.

Тексты основаны на брифе и локальной структуре курса `aveno-starter-structure-v4.md`. Четыре карточки результатов содержат оригинальные векторные иллюстрации. Стоковые фотографии не используются. Отзывы, статистика, скидки и другие неподтверждённые обещания не добавлялись.

Реальные скриншоты платформы не были предоставлены. В блоке «Внутри Aveno Academy» предусмотрено место для них, но выдуманный интерфейс не выдаётся за реальную платформу. После получения скриншотов замените типографическую композицию `platform-type` либо добавьте галерею после `benefits-grid`.

## Проверка

Браузерные проверки находятся в `qa/check.cjs`. Для запуска требуется Playwright и установленный Chrome; путь к Playwright задаётся через `PLAYWRIGHT_MODULE_PATH`. Проверяются адаптивность, новая структура, четыре SVG-карточки, меню, FAQ, CTA, валидация формы и содержимое WhatsApp-сообщения. Тест не отправляет сообщения.

Размещение на Sites описано в `.openai/hosting.json`. Публичный доступ включён по запросу владельца. При обновлениях сохраняется тот же адрес: https://aveno-academy.swqqs.chatgpt.site.
